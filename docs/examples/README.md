# Examples

Request and response examples for both APIs this service speaks, kept as a reference.

| File | What's in it | Where the examples come from |
|---|---|---|
| [service-api.md](service-api.md) | **The service's API** (`payment-api.yaml` + the extras in [api-extensions.md](../api-extensions.md)): every endpoint, success and error cases (37 examples) | **Generated by running the real service code** against a scripted MarketPay, with a fixed clock. Never hand-edited. Regenerate with `docker compose run --rm --no-deps api uv run python scripts/generate_api_examples.py`. |
| [marketpay-api.md](marketpay-api.md) | **MarketPay's Cloud API** (`api.json`): what the service sends, and what staging answers, for every endpoint and case | **Observed on staging** wherever an observation exists. The spec's shape is used only where staging never produced the case, and is labelled "spec only". Real card data is redacted. |
